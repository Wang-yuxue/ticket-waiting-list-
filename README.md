# ticket-waiting-list
## 数据结构课程设计：火车票候补排队模拟系统

### 一、项目概述
本项目为数据结构课程作业，使用C语言**链式队列**模拟火车票候补购票业务场景。
在现实购票场景中，如果目标车次车票售罄，乘客可以提交候补订单，进入候补排队队列。当有乘客退票、改签释放车票时，系统按照排队先后顺序分配车票，先排队的人优先获得车票，符合队列**先进先出（FIFO）**的核心特点。

本程序使用链式队列实现，采用动态内存分配。和顺序队列相比，没有固定容量限制，可以根据候补人数动态开辟内存空间，不会出现数组大小固定导致的空间浪费或者队列满的问题。

### 二、数据结构设计
采用链式队列，包含结点结构体与队列头尾指针：
1. 队列结点：存储旅客姓名，指向下一位候补旅客的指针
2. 队列结构体：队头指针front、队尾指针rear
- 入队：新候补旅客添加到队列尾部
- 出队：有票时取出队首旅客，分配车票，释放该结点内存

### 三、程序功能介绍
1. **候补入队**：输入旅客姓名，将旅客加入候补队列末尾；
2. **出票出队**：若有车票释放，排在最前面（队首）的旅客成功买到车票，移出队列；
3. **查看候补名单**：遍历整个队列，打印当前所有正在排队的候补人员；
4. **退出程序**：程序结束前释放全部动态内存，防止内存泄漏。

### 四、编译与运行方式
本项目标准C语言编写，Windows平台下可使用 Dev-C++、CodeBlocks、Visual Studio 等编译器直接打开运行。
